# Changelog

## 0.1.3 — 2026-09-06

- Add `AsyncNinjaChat`, async streaming, and async context management for Python.
- Add clients for batch requests, model comparison, pipelines, presets, estimates, pricing, embeddings, reranking, speech, native Messages, and session exports.
- Add account-management resources for keys, projects, usage, audit records, and webhooks.
- Improve timeout enforcement, cancellation, stream cleanup, malformed-response errors, and retry handling.
- Update generated TypeScript types and the bundled OpenAPI contract.

Node.js 18+ and Python 3.10+ remain supported. Account-management calls require a separate management key.
